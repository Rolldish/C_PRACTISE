## 目录

```text
days/
├── day01/  输入输出、条件与循环
├── day02/  数组、字符串与函数
```

## 开发环境

- Windows
- Visual Studio / MSVC
- C++ 控制台程序

## 学习原则

1. 每天先学习最少必需知识，再独立完成代码。
2. 每个功能完成后进行边界和失败场景测试。
3. 每天验收通过后提交一次 Git 版本。
4. 保留每天的代码快照，用于观察项目演进过程。
